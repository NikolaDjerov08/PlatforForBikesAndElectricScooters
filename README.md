# Платформа за велосипеди и електрически тротинетки

Уеб платформа за наемане на велосипеди и електрически тротинетки, разработена на C# с ASP.NET Core MVC.

## Концепция

Платформата свързва потребители, които искат да наемат превозно средство за кратко време, с наличните велосипеди и електрически тротинетки в града. Потребителят разглежда наличните превозни средства, избира едно, наема го за определен период и плаща според продължителността на наема.

## Цел

Целта на проекта е да се създаде лесна за използване уеб платформа, която улеснява наемането на екологични превозни средства и дава на администратора удобни инструменти за управлението им.

## Основни задачи

- Проучване на съществуващи платформи за споделена мобилност.
- Проектиране на базата данни (потребители, превозни средства, станции, наеми, отзиви).
- Създаване на начална структура на приложението (ASP.NET Core MVC).
- Регистрация и вход на потребители с роли (потребител и администратор).
- Каталог на превозните средства с търсене и филтриране.
- Наемане и връщане на превозно средство с изчисляване на цената.
- Административен панел за управление на превозни средства и станции.
- Тестване и писане на документация.

## Очаквани резултати

- Работещо уеб приложение с регистрация, каталог, наемане и административен панел.
- Релационна база данни, създадена с Entity Framework Core.
- Пълна документация на проекта.

## Планирани функционалности

| Функционалност | Описание |
| --- | --- |
| Акаунти | Регистрация, вход, профил, роли |
| Каталог | Списък с велосипеди и тротинетки, филтри по тип, цена и станция |
| Наеми | Наемане, връщане, история на наемите, изчисляване на цена |
| Станции | Места, от които се взимат и връщат превозните средства |
| Отзиви | Оценка и коментар след приключен наем |
| Админ панел | Добавяне, редакция и изтриване на превозни средства и станции |
